# 原创荒野素材

v0.20 使用内置 imagegen 生成原创地表和透明道具，Pixelbolt 继续提供既有角色身份、身体动作和装备。未复制任何现有游戏人物或地图。源 PNG 保留完整像素与透明度；`manifest.mjs` 以图集帧引用源矩形，不重绘或裁剪修改生成图。

`ground_ink.png` 为 1536×1024 的全可走地表纹理。提示词：原创俯视荒野游戏地表，墨线、炭笔排线、水彩纸质，低饱和鼠尾草绿、橄榄苔色、赭黄泥土与风化灰土，大片留白；左上暖色空地，右下冷色苔地；无树、岩石、建筑、水、悬崖、人物、道路、文字、网格、UI，所有实体另画，非像素或3D。

`props_ink.png` 为 1536×1024 透明六对象图集。提示词：原创荒野游戏道具，三列两行，各自独立留白，共用地面接触线；墨线排线、粗细不匀手绘轮廓、低饱和水彩剪纸感；上排为不对称松树、弯曲阔叶树、灰石矿脉，下排为带赭红果实的灌木、裸根树桩、浅黄花草药；无背景、文字、边框、其他游戏内容。

生成器实际的上排接触线约 y570、下排约 y974，与提示的规则格不完全相同，图集按实际 alpha 边界定义：上排 y0..600，下排 y600..1024；接触点在每帧 x256、y570/374。前端以 native_scale=0.22 换算到游戏原生单位，身体、碰撞和点击锚点不得按整张图大小猜测。

构建：`node scripts/build-pixel-world.mjs` 最后调用 `applyWildernessAssets`，复制原始资源并生成图集和总 manifest。运行 `npm run build`、`npm run maps:check`、`node deploy/check-pixel-assets.mjs` 验证。Tiled 保存独立实体脚底和碰撞；手绘地表不提供碰撞。`v019-map-baseline.json` 记录旧地图阻挡，新增测试保证所有旧合法格仍可走。

## v0.20 组合方式与体积

两个场景共用无路径、无实体、无水的地表纹理；`src/wilderness-art.js` 分别定义广场道路和林地—山脊—药草区道路。Phaser 和兼容 SVG 读取同一数据，池塘仅覆盖各自 Tiled 阻挡 footprint，边缘是不规则岸线和芦草。纸色覆层降低底纹对比，实体轮廓保持清晰；覆层不修改源 PNG，不参与碰撞。夜色由服务器 phase 叠加，不按客户端时间推算阶段。

这是混合画风：环境树木、矿石、灌木和地表是原创墨线/水彩剪纸素材；原 AI 的 Pixelbolt 四方向身体、怪物、武器、护甲与农具身份保持。远处旧书屋/建筑继续使用已授权 Pixelbolt 图集。本期新增斧头和镐的三级动作叠层，以及浆果、月光草、旅行口粮、月光炖菜图标。未宣称全部素材已经改为手绘动画。

实测未压缩发布目录 190 个文件、12,330,684 字节，其中 94 个 PNG 共 6,878,820 字节；manifest 实际引用 91 个 PNG，另有 3 张旧地图 PNG 保留但不请求。两张新源图均 1536×1024：地表 3,980,079 字节，道具透明图集 2,378,736 字节。其余是角色/工具图集和 JSON 帧信息；这些数字是磁盘体积，不是同时驻留内存。构建不需要肥鱼运行生成模型。

新增验收：`node --test tests/v020-ui-state.test.js tests/tiled-map.test.js`，以及 `npx playwright test tests/browser/wilderness.spec.js`。真实画布证据见 `artifacts/v020-wilderness-overview.png`、`v020-tree-working.png`、`v020-tree-depleted.png`、`v020-quarry-working.png` 与三尺寸夜景。浏览器可点选资源详情，但旁观操作不发送 AI act；实际砍树/采矿由测试接入的原 AI 通过 MCP 发出。
