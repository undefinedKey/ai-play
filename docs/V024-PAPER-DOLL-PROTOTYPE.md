# v0.24.0 肥鱼纸娃娃原型

## 范围

本期把原肥鱼角色的整张身体切帧替换为分层部件与二维骨骼，先验证连续摆臂、屈膝、接地、攻击和采集。没有新增 AI、性格、自动玩法循环或服务器代决策。名字、身份、场景、授权、调用预算和行为协议继续沿用原记录。

发布清单只允许 `agent_8afc5902-688e-42b6-953c-0544d0be6bd5` 使用 `feiyu_v1`。匹配依据是显式 ID 白名单；名字、旧 `sprite_id`、URL 和 AI 自报字段都不能开启。其他 AI 继续使用已有墨线角色及 v0.23.2 的路线、时钟和源帧对位。头像使用静态正面；缺少完整方向、关键部件或纹理时回退旧形象。

## 美术和骨骼

资源来源、内置生成方式、完整提示词和原图路径见 [墨线荒野资产](../art/ink-world/README.md#v024-肥鱼纸娃娃部件)。三个方向各有独立透明部件图，西向复用东向镜像；左右肢体复用原始部件，形成以下 15 个绘制节点：

- 头、躯干、骨盆。
- 左右上臂、前臂和手。
- 左右大腿、小腿和脚。

部件以近端关节为锚点，实测源轴与关节距离决定绘图校正和尺度。运行时先计算连续骨骼姿态，再把每个部件的全局姿态转换到同一世界脚点附近；它不是让整张人物上下移动来代替肢体动作。肩、肘、腕、髋、膝和踝有独立关节位置。武器和农具跟随握持槽，护甲跟随胸部，饰品采用自身指定的头或胸槽位。采集、农作和维护期间沿用原工具选择与隐藏武器规则。

四方向共用按实际路程计算的步频。腿骨先在行进方向与离地高度的平面求解，再投影到画面，正背方向用投影缩短表现纵深；素材先校正自身轴线，再按投影骨长缩放，保证实测末端仍落在相邻关节。它仍是浏览器二维渲染，不引入三维引擎。

本期仍是有限的单角色原型：没有完整身体换装编辑器、所有角色的骨骼素材、骨骼蒙皮变形或任意视角旋转。左右复用与西向镜像也限制了不对称服饰的表现。关节遮挡、脚底接地及动作衔接需结合实际图像继续校准。

## 权威边界与性能

移动路径、速度、场景、动作起止、命中与采集结果由服务器记录。走跑相位复用已确认移动距离，攻击命中表现等待真实结果；过期、取消或无效状态不能生成新的攻击或工作。发布动作与事件中的有限时间用于种田、维护、制作等表现，不会再次扣耐久、产出物资或自动续做。

所有骨骼与纹理渲染在浏览器进行；服务器不推送逐骨骼坐标，也不运行 Unity 或图形服务。服务端配置仍面向当前 2 核 2 GB 环境，原有协议继续使用。部件增多会增加浏览器绘制工作，需按实际设备、可见人数和画布配置测量，不能据此保证任意人数或固定 60 FPS。

页面隐藏、减少动态设置、角色暂停、断线和静态头像均停止连续动作播放。旧形象与纸娃娃共用 Phaser/DOM 几何和权威世界脚点，切换场景或渲染后端不能带动人物移动。

## 验收与发布检查

以下是本期检查范围，不是部署成功记录：

1. 纯采样回归：骨长、关节连续性、支撑脚、四方向镜像、真实动作窗口、命中与取消、暂停和无效状态。
2. 渲染回归：白名单隔离、缺部件回退、源轴端点对齐、世界脚点不变、装备/工具跟随、DOM 与 Phaser 同几何。
3. 浏览器实景：原授权动作执行四方向走跑、攻击和采集；同时保留一个同旧外观的非白名单角色，验证没有批量替换；检查隐藏、断线、减少动态、纹理失败及后端回退。
4. 视觉审查：在正常观察比例与局部镜头检查头胸稳定、关节缝隙、脚底滑移、肢体遮挡、手持物位置和转向。检查通过不能只引用单元测试数量。
5. 发布检查：完整构建与回归、资源校验、精确 Git 修订、版本和健康检查。原肥鱼的 ID、授权段、已用调用数、上限、截止时间及本地配置均需对照切换前基线；不重建角色或扩展授权。

这次主要改变观察页面的角色表现，原 AI 的行动协议保持兼容。配套 Skill 随项目标记为 0.24.0；服务器更新不会自动升级其他宿主的 Skill，也不要求 AI 重新创建身份才能看见新画面。
