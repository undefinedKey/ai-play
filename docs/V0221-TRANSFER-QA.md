# v0.22.1 图片传输视觉验收

本轮仅检查相同尺寸的 WebP 发布副本。原始 PNG 保留，世界坐标、裁切、碰撞和 AI 行为没有因编码调整。WebP RGB 为有损编码，不宣称与 PNG 像素完全相同。

## 实际 HTTP 对照

使用本地随机端口、生产静态路由与内存数据库。两名 QA 角色通过真实 MCP 动作种植、制作/装备与建造篝火；补充材料仅写入隔离 fixture，未连接线上角色。

新浏览器上下文分别发送 `Accept: image/png` 与 `Accept: image/webp`，URL 均保持 `/pixel-world/*.png`。每项图片响应均断言 HTTP 200、实际 `Content-Type`、`Vary: Accept`，以及 body 字节数等于 `Content-Length`。浏览器没有写请求、cookie 或脚本异常。采用减少动态效果设置，保持同一世界时刻，避免动画差异妨碍对照。

| 隔离场景 | 图片请求数 | PNG body 字节 | WebP body 字节 | 减少 |
| --- | ---: | ---: | ---: | ---: |
| 白天广场 | 7 | 15,915,524 | 2,521,798 | 84.2% |
| 农田 | 4 | 9,680,116 | 1,565,142 | 83.8% |
| 展开装备目录 | 7 | 15,915,524 | 2,521,798 | 84.2% |
| 夜间篝火 | 8 | 18,300,234 | 2,927,656 | 84.0% |

这些是该 fixture 的实际图片响应体，不是所有线上角色的统一首载体积，也不代表网络耗时减少相同比例。JS/CSS gzip 和线上首载耗时由主任务另行验证。

## 视觉检查

完成 1440×900、390×844、390×900 三个视口的 PNG/WebP 配对截图，共 36 张地图或装备截图，另保留首屏图。白天和夜间地图均检查默认 200% 与近景 400%；农田和装备按产品本身的显示尺寸检查。

实际审看桌面 400% 角色、建筑、武器与夜间火焰，手机 200%/400% 角色，桌面/手机农田，以及桌面/手机装备目录：未见明显墨线断裂、透明白边、火焰边界方块或尺寸/接地点变化。手绘纸纹有轻微有损编码差异，但没有妨碍主体轮廓与细节辨认。没有为本次传输补丁修改产品 CSS 或原始素材。

本地证据保存在被 Git 忽略的 `artifacts/`：

- `v0221-transfer-visual-check.mjs`：可重复的 HTTP、真实动作与截图脚本。

- `v0221-day-{png,webp}-1440x900-4x.png`、`v0221-night-{png,webp}-1440x900-4x.png`：桌面近景。

- `v0221-equipment-{png,webp}-390x900.png`：装备小图标的浅背景透明合成。
