# v0.19 第一阶段：真实移动、战斗动作与旁观镜头

基线：v0.18.0 / `767184a07e9f0193a881e88f0205893a7215ea93`。本文件是实施与验收约定，不是已完成声明。

## 目标与边界

原 AI 决定目标、步行或奔跑、继续或撤退。服务端执行有限授权中的路径和动作，客户端呈现真实状态。保留原人格、身份、专属外观、主人目标、预算和期限，不增加活动轮换或离线替身。本期只改移动、动作与旁观体验；环境实体化、昼夜、共同营地与更大规模另行分期。

地图优先、温暖广场与冷色林地延续现有像素美术。原农田、装备、工具、料理、交易、合作和历史保留。旁观只读，无人物列表；直接点选地图角色。视口与状态的详细验收见 `V019-UI-CONTRACT.md`。

## 权威状态

- `position` 表示当前真实坐标，可为连接两个合法导航格的水平或垂直边上的小数；导航目标仍为合法格。所有射程、入口、交互和距离规则以实际位置为准。
- `movement` 是有唯一 ID、场景、路径、开始/结束时间、模式和速度的有限运动。行走和奔跑具有不同实际速度与耗能；按实际完成的距离计费，停止不收取未走完路程的费用。
- 方向使用 north/south/east/west。浏览器对时间采样受最后确认时间和预测上限约束，断线不无限推演；镜头、名字、气泡、装备和选区使用同一位置。
- 攻击有唯一动作 ID、准备、命中与恢复时间。命中时验证目标存活、同场景和实际距离，只结算一次。受击信息引用真实结算。
- 中断、暂停、到期、失联、重启与目标消失有明确结果，不恢复未确认伤害，不在重连时补演历史攻击。
- 模拟、广播和绘制频率独立。模拟目标 100ms，旁观广播目标 200ms，静止不为满足频率而制造事件。不得每帧调用模型或写完整存档。

## 接入与授权

旧动作默认 walk；新客户端可显式选择 run。沿用有限 adventure_plan；stop 可停止移动但不改变场景。动作受理不等于到达。运行器识别真实动作与失败，重新观察后由原 AI 作出决定。保留 2000 UTF-16 桌宠上下文、原能力集合、幂等动作、预算持久化、单执行者锁、主人本地目标锚点与旧 Skill 兼容。

## 验收矩阵

1. 移动：中间位置、速度、实际耗能、四向转弯、绕障碍、改道/停止、追击移动目标、入口切换、无路/越界/目标消失。
2. 战斗：准备时不扣血、命中时重检、恢复期不重击；受伤/死亡/撤退/暂停/失联/期限结束；延迟和重连不重复伤害或补演。
3. 表现：四向走跑与攻击/受击，工具装备锚点、前后遮挡、真实图集关键姿态；真实画布截图与动画检查。
4. 镜头：拖动、缩放、跟随、复位、全屏；手动拖动退出跟随；跨场景策略；桌面键盘和手机触控；减少动态效果与可关闭声音。
5. 只读与恢复：看图和镜头操作无角色动作；断线、空场、加载、错误、部分素材缺失可理解；无观众不停止授权中的世界。
6. 回归：账号、身份、外观、存档、仓库、农田、农具、装备、疲劳、合作、历史、Skill 及主人权限。
7. 性能：肥鱼隔离环境至少 5 个脚本控制端、100 个旁观连接、300 秒真实墙钟；应用与压测客户端分开报告 CPU/RSS、流量、同步 p95、错误和断线。脚本不是真实 AI 自主性证明。
8. 发布：完整测试与浏览器证据、精确 GitHub 提交/版本、备份、迁移验证、失败回滚、原桥状态恢复与线上实际版本/原 AI 接入验证。
