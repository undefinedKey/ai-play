# v0.22 手绘墨线荒野验收

## 实现范围

世界实际引用的 21 张手绘 PNG 覆盖八种人物、三种怪物、建筑、树木与矿石、道具、农田与作物、火焰与灰烬、工具、装备、饰品和库存图标。原图在 `art/ink-world`，发布文件逐字节一致。全套方向、动作、脚点和持物使用同一元数据，西向镜像东向；现有身份及世界坐标保持不变。

游戏界面使用炭墨边框和纸色信息，地图保持主要位置；资料可展开，不增加旁观人物列表。营地设施与资源堆缩小，空闲资源的亮色提示仅在指向、聚焦或选中时显示。道路使用不规则低对比边缘，池塘在既有阻挡范围内呈不对称岸线。农作区仍为独立近景，田地不会出现在冒险场景中。

Phaser 仅请求当前场景用到的图集，遇到后续新动作图片再加载。桌面使用 3072×2048 绘图缓冲，手机保持 1536×1024；逻辑世界均为 1536×1024，地图仍是 48×32。服务器不执行绘图或模型推理。桌面多用约 18 MiB 的颜色缓冲空间，不等于整个浏览器 GPU 内存开销。

浇水动作修复了四帧引用同一图导致不动的问题；休息增加轻微呼吸，并保留固定脚点。每个显示实例使用当前服务时间锚点，避免校正后的时间重用旧缓存而跳过短暂受击阶段。暂停、离线与减少动态设置仍停止动作播放。

## 验证记录

- 全部 Node 测试：760 项，757 通过，3 项按环境跳过，0 失败。最后动作修复后，26 项素材、动作与渲染相关测试再次全部通过。
- 最终统一浏览器回归：31/31 通过，涵盖农田、人物动画、怪物战斗、连续三个攻击/受击周期、镜头、Phaser、独立场景、昼夜、生存、断线和兼容显示。首次回归发现的浇水静帧与展开面板对比度已修复；战斗测试按真实当前阶段推进时钟，保留原有动作与伤害断言。
- 静态发布检查：实际 PNG 哈希、尺寸、透明性、采样边界、跨图补帧、源锚点、同步动作、碰撞边界、入口与全图可达性通过；单张纹理均不超过 4096×4096。
- 实景检查：1440×900、390×844、390×900 的广场、冒险、农田；真实开垦、播种、浇水与生长；白昼、夜间实际篝火与烧尽灰烬；仓库、装备与工具详情；八种形象、三种怪物、四向动作及持物；兼容图层与桌面/手机切换。
- UI 状态：加载、空世界、初始 503 与重试、部分资料缺失、只读权限、断线及减少动态；逐步修复展开农具、生活结果与档案的文字对比度。
- 隔离测试使用内存数据库与测试角色，不在正式世界创建演示人物。公开页面的库存/授权/私人目标隔离与无写请求继续验证。

Linux 发布门会在切换前重新执行全部 Node 测试、构建、静态检查与 30 秒模拟基准；通过后才备份并切换。线上验收检查精确提交、健康版本、原 AI 身份/预算/配置、数据库完整性，以及三场景九视口的只读访问。详细线上日志保存在本机 `artifacts/feiyu-*-v0.22.0.*`，与本地截图分开记录。
