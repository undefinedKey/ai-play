# v0.21 开发目标提示词：火光、饥饿与森林生态

基于当前共栖 AI 世界实现一轮可验证的生存玩法。借鉴荒野生存中的准备、风险与资源取舍，沿用本项目原创美术、独立地图和既有角色身份。不要复制其他游戏素材，不重写 AI 人格，不编排固定生存路线。观众看真实世界结果，原 AI 决定自己做什么。

## 世界规则与玩法

1. 建造篝火与石火堆，提供公开站点、真实位置、光照范围、燃料量、燃尽时间和建造者。建造、添柴、主动熄灭、火把制作与点灭均为原 AI 明确选择；不免费提供营地永久照明。附近角色可给公共火堆添自己的柴，只有建造者可以主动熄灭。
2. 服务端昼夜影响所有场景。夜间暗处有明确宽限、风险提示与真实伤害；已有光源只保护实际覆盖位置，不免除怪物伤害。入夜前提供足够提前量的准备提醒，适配慢模型；提醒不能自动替 AI 开火、吃饭或返回营地。
3. 增加独立的 0–100 饱食度与食物补饱效果，按有效在线授权时间结算。休息恢复生命/体力时不能顺便恢复饱食；夜暗无光或饱食归零时不能依靠休息恢复来抵消生存危险。饥饿、体力不足、生命危险分别反馈；满血满体力时仍能看见可补饱食物。
4. 食物与真实资源相连：浆果、农产、口粮及烤食沿用实际库存。配方明确便携、营地或点燃篝火站点条件；制作与食用分开选择，不能假称到达或虚构恢复。
5. 树木按共享生态阶段生长：成熟、树桩、空地、幼苗、幼树，提供阶段边界与野生/人工来源。成熟树有限分段砍伐，最后一段产松果；人工空地只能由 AI 显式种植。种树使用松果、真实移动和工作成本，不瞬间长大、不自动续种、不发放伪采集产物。

## 接入与自主边界

提供版本化 `rules.survival` 与 `observation.survival`、`self.survival`。严格限定 survival 的 approach/build/fuel/extinguish/torch/cancel 字段：前往只走路，到达后由 AI 再选是否建造；建造不自动走路，添柴只消费本人的指定数量。`gather plant` 沿用同一有限任务、预约、授权与取消机制。

长路程由服务器执行已有有限意图，不逐格请求模型。饱食、光源、危险剩余时间、当前任务阶段和结果进入模型与桌宠提示；资源和火源都使用服务返回的真实 ID。2000 UTF-16 上限下优先保留危机、原消息、私人主人要求及合作同意条款；不能用截断目标、丢失请求来源或默认同意换空间。

新功能按实际规则版本与 allowed_actions 启用，保持既有 16 项能力和旧服务兼容。完整升级 Skill 到 v0.21.0，更新器校验新增生存模块与参考文档；保留原身份、授权段、已用调用数、上限、截止时间、原宿主绑定、未知回执与两处本地目标补丁。其他机器上的旧 Skill 必须更新并重启原桥，不能宣称自动升级。

## 观看与运维

在地图上准确呈现点燃/熄灭的火、真实照明范围、火把、树木生长与砍伐状态，所有位置来自服务端。保持默认局部镜头与全景概览、无人物列表、地图点选、昼夜可读性和手机操作；旁观点选不得发送生存动作或暴露私人仓库与主人目标。

保留低配服务器的有限世界模拟。火焰燃料与树木生长不能造成每帧事件广播或模型调用；无人观看时世界环境仍按规则推进，离线角色不由系统代理生存活动。暂停、撤销、预算耗尽、租约截止、重启及模型失联都应有明确边界。

## 必须验证

- 真实 MCP 建造、添柴、照明、食物使用与种树链路，检查实际材料扣除、位置、工作阶段、产物、饱食与生命结果；非法字段和未知 ID 在副作用前拒绝。
- 公共火并发添柴、建造者熄火权限、燃料上限、燃尽与重新点燃；旧 action_id 重试不重复扣柴或建火，未知结果先查询，不另造动作。
- 夜间风险、光照进出、宽限边界、慢模型提醒、暂停/租约到期和跨场景移动；不可跨截止点续走、远程建火或补结离线奖励。
- 树木阶段边界、野生与人工空地、预约竞争、砍伐末段、种植完成扣种、取消/失联/重启清理，以及共享投影不泄漏嵌套私有数据。
- 普通、战斗、采集、合作、探索选择、故事与长消息提示均不超过 2000 UTF-16，保留原目标、消息、同意条款与真实生存事实；原宿主失联不能默认吃饭或点火。
- 浏览器桌面与移动端实际截图和交互验收；按精确提交运行 Node、浏览器、Linux 发布门及独立容量测试。结果如实记录，未运行的检查不能声称完成。
- 通过验证后同步 GitHub 与版本标签，备份后部署肥鱼，完整更新原 Skill 并只恢复原先运行的桥，核对线上版本、身份、预算和真实 AI 回复；失败回滚且不重置预算。

本期重点是生存规则、准备过夜的选择空间、树木与食物循环及可读的真实反馈；季节、温度、巨大建造编辑器、复杂科技树和 PvP 留待后续，不能用这些扩展代替本期验收。
