# v0.17 独立场景与像素世界验收

日期：2026-10-31。范围以 [场景契约](V017-SCENE-CONTRACT.md) 为准。

## 行为与画面

- 广场与冒险林地拥有独立 `scene_id`、地形与入口。旁观者切换页签只改变镜头；人物不会复制到另一张地图，也不会被镜头点击移动。
- AI 选择探索、狩猎、返回或休息后，已有有限计划沿合法路径走到入口、跨场景，再走向目标。普通移动不触发跨门；取消、暂停、离线和重启保留实际场景。
- 农作区是广场农田的近景。种田、营地恢复、附近聊天和邀请均校验所在场景；已有小组可明确使用远程组信。
- 村落与林地采用不同地面、房屋、树木、石块、遗迹和指路入口；人物与道具按脚底位置遮挡，移动动画逐段使用服务端路径。
- 保留旧人物、怪物、装备和农具的 54 张原图；只替换旧场景底图并增加场景/道具。最终 76 张 PNG 共 214,078 字节。
- AI 的身份、个性、主人目标、模型调用授权和预算保持原有规则。服务器提供地形和动作结果，不增加代替 AI 选择玩法的策略。

## 自动化与渲染

完整 Node 回归 `npm test`：579 项，576 通过、0 失败、3 项按环境/长探针开关跳过。三项分别在独立 Linux 演练和实际长探针中补测通过。默认命令与发布准备阶段一致按文件串行运行，避免固定墙钟用例在多进程负载下产生假失败。

- 新增真实 HTTP/MCP 场景用例：相同坐标跨场景不可近聊、实际入口往返、只读页签、跨门旧动作返回 `STALE_ACTION`、农作区域限制及原授权不变。
- SQLite 迁移验收覆盖 7 类真实旧状态与 8 类篡改，独立核对场景推断、坐标修复、身份、库存、目标、历史和私有迁移记录。旧历史不补造跨门经历。
- 浏览器完整运行 70 项，69 项通过；唯一失败为旧空场文案断言。修正该断言与寻宝测试的合法路径驱动后，受影响的 3 项全部通过，产品代码未因该复验改变。
- 在 1440×900、390×844、390×900 实际渲染并检查场景、5 人长名字/同格说话、遮挡、真实 L 形路径、减少动态效果、键盘、横向溢出与 Axe 检查。加载、空场、缺失资源、断线、错误重试和匿名只读状态均有截图证据。
- 实际 60 秒模型/桌宠慢回复与 46 秒服务中断恢复共 17 项通过；保留原运行 ID、授权截止、调用预算和独立事件轮询。
- 肥鱼上用无生产目录访问权限的隔离 Linux 用户验证发布失败恢复和真实 SQLite 迁移：3 项发布恢复测试及 2 项迁移套件通过。

本地证据保存在忽略提交的 `artifacts/`：`v017-node-final-serial.log`、`browser-v0.17.0.log`、`games-v017-final.log`、`v017-ui-evidence.json`、`v017-long-recovery-model.log`、`v017-linux-drill.log`、`v017-linux-history-migration.log`。视觉证据格式检查通过；截图也已人工查看。

## 升级与限制

发布按精确 Git 提交准备代码、测试和构建，通过后才暂停原桥、备份数据库并切换服务；迁移失败时回滚旧代码与数据库。服务器上的完整 Skill 一并升级，保留两处既有本地主人目标补丁及配置；恢复原来运行中的桥，不启动用户暂停的角色。

旧版本没有明确场景字段：优先保留已有场景；有野外标记、非营地计划或待处理奇遇则迁移到林地，其余保守归入广场。只在旧坐标与新障碍冲突时移动到最近合法格，记录私有迁移凭据，不伪造游戏行动。

手机上五个角色同格同时说话仍可能遮住部分景物；可使用短预览、展开全文或定位镜头。自动无障碍检查与定向键盘验证通过，不等同于全面读屏器测试。
