# 2D 冒险版 v0.8.0 验证范围

## 功能与边界

- 真实 World、SQLite、HTTP/MCP：有限探索、单目标狩猎、回营地休息、撤退、停止、成长与奖励。
- 两个独立控制端自主邀请、同意组队、共同选择目标；按实际伤害分享一次总奖励，未参与者不获奖。
- 低血量停止当前计划并唤醒原 AI，重新选择继续仍可能战败；暂停、召回、过期、失联均停止执行。
- 关键结算同步落盘，重启不重复奖励；普通动作合并检查点，正常关闭刷新；计划重启后不自动继续。
- 公开字段白名单、真实空场、无旁观者时推进、动作幂等、旧动作淘汰后不能重放、日志与回执数量上限。
- 原 AI runtime / dsh-pet 桥：事件与计划复查驱动决策、独立心跳、实际错误反馈、调用预算、2000 字桌宠上下文上限。
- 游戏重复只提示建议，旧服务硬冷却仍可被新版桥理解；保留现场长期授权上限，默认额度与旧授权不增大。

## 浏览器

完整浏览器回归 26 项通过，覆盖登录、授权、邀请、Skill 配对、多人游戏、独处活动、旁观与冒险。随后针对增量同步竞态补充一项真实 HTTP/SSE 测试，冒险与旁观共 7 项重新通过，总计 27 个浏览器用例。

桌面 1440px 与手机 390px 均检查无横向溢出、Axe 无违规。截图中的测试角色仅存在于隔离测试数据库，不写入生产环境。

增量专项验证：HTTP 轮询先到、SSE 后到时不重复日志；位置恢复旧值也正确；清理日志与重连完整快照一致；服务器版本回退后界面可恢复。

## 小规模负载

`scripts/benchmark-adventure.mjs` 使用临时 SQLite、5 个脚本决策角色和真实世界规则，退出后清理临时数据。不会连接真实模型或生产角色。可在目标机重现：

```bash
node scripts/benchmark-adventure.mjs --realtime --seconds=30
node scripts/benchmark-adventure.mjs --seconds=1800
```

Windows 本地 30 秒实时样本：峰值 RSS 57 MiB、CPU 累计 94ms、最长模拟步进 3.13ms，增量消息约 3.7KB/秒/旁观者，相比完整帧减少约 79%。加速运行 30 分钟世界时间后，事件稳定受限于 3000 条，5 个角色的动作回执共不超过 1000 条。

这些是特定测试情景，不能作为最大在线容量保证；消息字节估算不含 HTTP/TCP 开销。加速模式的事件循环延迟不用于评估真实交互延迟。服务器发布脚本会在肥鱼上再次执行串行测试和实时探针，实际线上结果以部署输出为准。

## 未代替的验证

自动化中的模型和桌宠回复由确定性替身提供，用于验证原 AI 的决定能够实际执行、获得反馈并受权限约束。没有冒用用户现有 AI、模型密钥或私人记忆，不能声称已验证某个真实模型持续自主游玩的质量。新功能需要已有 AI 更新 Skill、重启原接入端并保持授权有效。

首版没有装备系统、复杂物理碰撞或无限开放世界；当前成长为等级、经验、金币与击杀记录，移动采用每秒一步的网格路径。异常进程崩溃可能回退最后 5 秒的非关键步进。
