# 全游戏美术规范：开罗式 Q 版像素风

确认日期：2026-11-04。用户确认：“整体游戏风格做成开罗游戏的画风就行。”

这是整个项目当前的美术方向，适用于现有场景的后续改造和所有新增内容。参考开罗游戏的大头小人、明亮像素场景、清楚的动作反馈和紧凑游戏界面，制作本项目自己的角色与素材。

本规范优先于旧版本中的《饥荒》式粗墨、纸片、怪诞手绘和低饱和荒野画风要求。旧文档保留为版本历史；其中与画风无关的玩法、状态、空间、身份和验收约束继续有效。

## 统一覆盖范围

| 范围 | 统一方向 |
| --- | --- |
| AI 人物 | 大头短肢、约 2–2.5 头身的 Q 版像素小人；通过发型、衣服、配饰和轮廓辨认身份 |
| 怪物 | 与人物相同像素密度和色阶，外形鲜明、表情清楚，实际大小与攻击范围可读 |
| 广场、旧冒险地图、横版森林、遗迹 | 明亮而有层次的像素地形、道路、树木、矿石、建筑和入口；区域之间保留空地与清楚的通路 |
| 农作区 | 像素田垄、作物与农具；开垦、生长、成熟、浇水和工具等级按真实状态区分 |
| 小屋与家具 | 建筑、室内、家具、书籍、纪念品统一像素比例；坐下、吃饭、阅读和休息有可靠的接触点与遮挡 |
| 装备、资源、食物与图标 | 世界中的持物和界面图标采用相同造型；木盾、铁甲、浆果、面包等按实际物品显示 |
| 界面、气泡与特效 | 简洁的像素边框、浅色信息底板、清楚的血条与数字；伤害、火焰、采集反馈统一风格 |

统一画风不改变各场景的视角与空间规则。横版冒险继续横向前进；广场、农场、小屋等按各自用途组织画面。旁观者切图只改变镜头。

## 画法与摆放

- 使用清楚的像素簇、阶梯轮廓和少量离散明暗色阶。白天以草绿、天蓝、暖木色和米白为主，夜晚按真实昼夜状态变化，保留主体可读性。
- 人物、怪物、树木、建筑、家具与图标应有一致的细节密度、光照方向和轮廓尺度。避免混入写实材质、粗墨纸片或模糊的大图缩小效果。
- 优先按实际显示尺寸绘制和检查。像素纹理保持清晰采样；文字使用清楚易读的中文字体，不要求正文强制像素化。
- 地面细节克制，资源与建筑成组摆放，给道路、入口、战斗和交互留出空间。装饰与可交互资源可辨，不能挤满整张地图。
- 脚底、家具座面、手持工具和装备附着点统一校准；动画与缩放不造成漂浮、滑步、穿脸或位置跳变。
- 沿用原身份、外观种子和识别特征进行像素化表达，不重抽角色，不改变 AI 的性格或记忆。

## 动作与战斗风格

走路、奔跑、攻击、受击、采集、农作、进食、阅读和休息要有可区分的像素姿势。走跑通过腿脚交替与小幅身体变化表现，速度与真实移动一致。

横版战斗采用清楚的交战站位和短促动作节奏：准备、短距离出击、挥砍或对应武器动作、收招；命中后表现闪白、局部后退和伤害数字。多人在场时保持角色可辨，不能把邀请或同组关系画成已经参战。

战斗意图、目标、是否继续或离开由原 AI 决定，世界只执行获准的有限行动。动画依据服务器动作时间线，命中特效与伤害数字依据真实回执；视觉位移不改变世界坐标、碰撞和射程。断线时停止推进动作，减少动态效果设置保留静态事实。

## 界面与平台原则

地图是旁观页面的主体，信息层保持克制。继续不显示常驻人物列表，支持直接点选角色、观察场景、缩放和跟随；气泡、名字与血条不长期遮住人物和关键动作。桌面与手机均需能看清实际游戏场景。

平台只提供世界服务与客观反馈。画风统一不新增固定性格、代选行为、自动组队、自动补给或强制活动，不改原 AI 的目标、记忆、身份和存档。

## 实施状态与验收

截至 v0.33.0，横版森林已有本方向的原创人物、怪物、场景、界面与战斗表现，可作为后续改造的项目内参考。其他场景仍有历史美术，后续按本规范逐步统一；本文件确认全游戏目标，不表示全游戏换装已经完成，实际进度以各版本验收记录为准。

每次改造按完整可见场景验收，包括角色、怪物、资源、建筑、物品、界面及动作，不能仅给地面换色或添加滤镜。至少检查桌面与手机的默认观察尺度、昼夜、长文本、实际移动与战斗、加载和断线状态。功能回归检查事实与交互，实景截图和动态观察检查画风、比例、摆放、动作与遮挡。

美术在浏览器端呈现，沿用现有世界服务；不因画风更换给 2 核 2 GB 服务器增加图片生成或游戏引擎进程。换素材时保留实际规则、资产语义、身份映射与存档，完成相应验证后再按工程发布流程上线。
