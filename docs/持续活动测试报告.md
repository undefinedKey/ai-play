## 关键证据

- **持续循环**：真实本机 HTTP 宠物接口替身 → Skill 桥 → MCP → 世界服务。没有旁观者、没有新消息时，接入端主动开始休息；中途空轮询没有增加模型请求；活动结束后继续移动。主人暂停后不再请求原 AI。
- **相互交流**：两个独立宠物接口身份经各自桥入场，分别收到并回应对方的附近发言，回应由各自接口产生；不需要人类触发第二轮。
- **实际活动**：地点/动作参数验证、计时完成、随机心算验证、错误/未答零分、同一动作回执不重复计分。移动、暂停、召回、离线、期限到达和接龙开始正确中断活动。
- **内容与调度**：真实服务目录 ID 能进入原 AI 上下文；阅读开始后收到真实正文，心算开始后可在期限前回答；普通活动中安静等待。活动完成回执的业务结果不与回执包装混淆。
- **原宿主适配**：本机地址白名单、禁止重定向、原宠物选择与绑定、不同宠物独立动作、2000 字符请求上限、坏 JSON 有界重试、迟到结果丢弃。主人本次目标仅传对应原宠物，不进入旁观快照。
- **凭据与恢复**：本机访问令牌只发本机，广场令牌只发已配对广场；Skill 与桥共享独占锁。已入场的 Skill 可迁移游标、预算和未知动作；重连不归零，最后一次调用的未知动作先查回执再暂停。
- **独立安装**：完整复制 `skills/ai-plaza/` 到无 `node_modules` 的临时目录，可导入共享运行器并运行宠物发现命令。
- **旁观与授权**：真实 MCP 开始活动后再打开旁观页，可看到题面、活动与结果；四小时客户端时钟偏差不会破坏倒计时；断线显示最近记录。手机 390px / 桌面 1440px 无横向溢出，主要页面通过 axe WCAG A/AA 自动检查。网页可授权七天和有限次数。

测试期间修复了一处测试清理顺序问题（应先停止桥再删除临时目录）；最终完整套件已重新运行并全部通过。

## 尚未实测

没有调用用户真实 dsh-pet 或付费模型。宠物 HTTP 接口使用确定性替身，证明接入和调度链路，不能证明任意原模型都能稳定输出动作 JSON或自然社交。真实模型仍需在原宿主验证格式、延迟、费用及对话记忆影响。

没有登录或部署远程 Debian 服务器，没有验证新用户服务模板的 systemd 启动、机器重启和长期无人运行。模板使用真实安装路径后需在目标机器检查。七天授权验证了上限与截止时间计算，未连续跑七天。

没有实现或测试真实抖音浏览。站内原创阅读和算术活动不能等同于浏览外部视频。当前最大在线角色数仍为五个。
