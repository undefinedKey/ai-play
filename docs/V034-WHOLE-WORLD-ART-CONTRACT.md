# v0.34 全世界 Q 版像素美术契约

本次按 [全游戏美术规范](ART-DIRECTION.md) 统一已有世界的画风。风格参考为明亮、短肢大头、离散色阶、清晰动作的开罗式 Q 版像素，角色与素材使用本项目原创绘制。

## 覆盖与工程边界

- 广场、旧冒险、遗迹的地面、建筑、道路、树木、矿点与入口使用原生像素素材；农田近景、作物阶段、工具等级与仓库物品同步更换。
- 八种已持久化的角色外观及三种旧场景怪物使用同一密度的方向图集，装备、配饰和工具随真实动作同步。外观 ID、身份、颜色来源和已拥有的物品保持原值。
- 小屋、室内、六类家具的四个朝向、纪念品、书籍、持物和公共场地使用同一套像素语言。家具继续依真实放置坐标、旋转、座面和前景遮挡绘制。
- 横版森林保留已上线的原生 Q 版像素表现；其站位与规则不扩展到其他场景。公共界面、名字、气泡和详情使用米白、草绿与暖木色，保持可读中文和键盘操作。
- 旁观切换、缩放和角色点选不写入世界。没有常驻人物列表。后台不代替 AI 决定行动，不重设目标、记忆、人物或存档。

## 素材与渲染契约

`scripts/build-q-world.mjs` 是可重复执行的世界图集生成入口。`art/q-world` 保存整数像素绘制源，发布的 `q_*.png`、图集与 manifest 是其输出。manifest 使用 `render_style: q-pixel`，保留现有语义 ID 与来源说明；`texture_sha256` 校验每张已生成纹理。部署检查比较生成输出与构建副本，并检验图集矩形、脚底锚点、附着点、动作阶段、地图碰撞和入口连通性。

原有粗墨图片与 `art/ink-world/v033-manifest.json` 保留作历史回归材料，当前 manifest 不引用它们。历史纸娃娃测试继续保护原来的测量与渲染能力；当前角色的身体、装备、工具和配饰由同步方向帧组合，不用旧粗墨专属角色覆盖新画风。

原生像素在 DOM 与 Phaser 中共享源帧、脚底和实际动作时间线，最近邻纹理采样不应把真实移动强制锁成逐格跳跃。屏幕位移保持连续，攻击命中和受击只来自服务器事实。减少动态与断线状态不继续虚构动作。

小屋使用原生整数几何像素图形，保留已测量的布局占位、接触点和遮挡契约。历史 v028 图源仍受完整性检查，当前显示不请求其旧图片。

## 验收与发布

1. 执行全量逻辑测试，检验新图集方向、像素边界、动作同步，以及历史身份、授权、经济、家具和世界逻辑的回归。
2. 构建浏览器产物并执行部署资源检查；所有当前可达世界纹理必须为 Q 像素，旧艺术只能通过明确的历史测试加载。
3. 隔离世界中通过真实 HTTP/MCP 创建角色、移动、种田、布置和使用家具，检查桌面、手机、实际画面、昼夜、加载、减少动态与 DOM 备用渲染。
4. 同步 GitHub 的同一提交，在 Debian 上先准备、测试和构建，再备份并切换。发布后核对原角色、原授权、调用额度、原配置与完整 Skill，生产旁观仅执行读取。

实际测试结果、提交和服务器备份由当次发布报告记录；本契约不代替测试结果。
