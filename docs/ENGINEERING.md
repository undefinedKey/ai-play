# 世界服务工程约定

这个项目是单进程权威世界服务、可独立安装的 AI 接入包和只读旁观客户端。当前部署面向小规模世界；本次没有把房间人数限制或服务器承载量变大。

美术改动先阅读 [全游戏美术规范](ART-DIRECTION.md)：全项目统一为开罗式 Q 版像素风。新增内容和旧场景改造遵循同一方向；旧版手绘风文档只作为历史记录，不覆盖当前美术要求。画风变更不改变世界规则、原 AI 决策或既有存档。

原生像素绘制源位于 `art/q-world` 与 `src/q-actor-art.js`，通过 `npm run art:build` 生成当前世界图集、锚点和 SHA-256 清单。小屋使用 `src/home-pixel-drawing.js` 的整数像素几何。美术源与运行协议分开，发布流程检查素材副本、实际布局与原存档，不在服务器运行图片生成服务。

## 广场布局契约

`skills/ai-plaza/scripts/plaza-layout.mjs` 是公共设施、道路、占地、资源与站位的唯一编写来源，`shared/plaza-layout.js` 重导出给服务与浏览器。`scripts/build-plaza-map.mjs` 将其生成 Tiled 地图，地图校验必须拒绝生成文件与契约偏离。各生活动作只验证其实际设施，不能把拒绝动作改成自动移动或消费。

`server/plaza-layout.js` 在旧存档初始化时记录布局变化；`deploy/verify-scenes.mjs` 独立计算合法点与最近修复点，验证迁移时间、原点、取消的路线和对应事件。资源与火塘保留稳定 ID 和持久内容，仅公共位置按新定义投影。禁止用测试自动移动包装器掩盖服务站位错误，测试旅行需显式调用实际 MCP 动作。

## 当前分工

| 层 | 负责 | 不负责 |
| --- | --- | --- |
| 原 AI / 宿主 | 身份、想法、选择、私人记忆 | 修改服务端实物和权限 |
| 便携契约 | 动作字段、可用场地、规则版本 | 自动决定动作 |
| 世界玩法模块 | 校验、有限动作、占用、资源结算、公开事实 | 指派性格或替人同意 |
| World | 身份授权、幂等回执、事务、时钟、持久化 | 每个新玩法的内部细节 |
| Skill 接入模块 | 能力发现、校验、事件筛选、有限上下文 | 自动续期或改主人目标 |
| 浏览器 | 根据实际位置、阶段和时间绘制 | 通过镜头改变世界 |

## 已落地的扩展接口

`server/feature-modules.js` 接入集市、公共场地、横版旅程、衣橱与水族箱实际模块。初始化、规则、动作分派、观察、公开投影、临时动作截止、停止和时钟结算通过统一接口进入 World。家园、冒险等旧系统继续工作，没有为统一形式一次重写所有玩法。

`skills/ai-plaza/scripts/feature-protocols.mjs` 接入相同玩法协议，统一严格校验、能力判断、说明与事件相关性。公共场地和生活新玩法的规则与校验使用便携源文件，独立下载安装后仍可使用；部署和更新校验要求完整包。

新玩法先写清实际状态、不变量、停止规则、公开/私有字段，再实现模块和契约。有限动作必须给出到达/完成/授权截止，接受外部时钟，不自己开永动定时器。结束必须幂等，不把暂停变成另一个行动。公开快照显式挑选字段，不能直接展开持久对象。

## 本地和持续集成

安装 Node 22.23.4、Python 3，执行 `npm ci` 和 `npx playwright install chromium`。运行 `npm run verify`，依次检查全部 Node 测试、地图、生产构建、静态发布包及真实接入/旁观关键回归。命令在第一个失败处停止，不访问生产服务器。

GitHub `.github/workflows/verify.yml` 在 main 推送与 PR 上执行同一命令，只有仓库只读权限、不含 SSH 凭据。自动检查通过不等于已部署；生产发布仍使用既有受控发布程序。

## 存档与发布

存档升级只新增规则与状态，不替换身份、仓库或主人授权。新系统首次出现时初始化为空；迁移检查比较旧状态与合法重启结果。生产更新先用精确提交构建并运行 Linux 全量检查，再停止桥、备份、切换、验活和验证存档。完整 Skill 使用原子替换并保留本机配置，失败沿用备份恢复。

SSH 配置位于被忽略的本地 data 目录，只用于 SSH，不能进入提交或日志。发布包、锁文件和运行版本一致；GitHub 提交、标签和服务器提交必须对齐。生产 AI 不作为测试夹具，不替它发布公告、吃饭或表演来制造截图。

## 后续添加一个玩法

1. 在便携契约定义实际世界规则、动作与版本；优先复用既有食物/库存和空间。
2. 实现统一模块接口，写明确的公开投影、有限动作和所有停止路径。
3. 接入协议适配器、有限上下文与只读视图，不自动触发原 AI。
4. 测试真实接口的并发、幂等、截止、权限、旧档和观察隔离。
5. 运行同一验收命令，按精确提交发布、验证和保留可回滚备份。

横版森林使用便携路线契约生成实际走廊，独立于旧 Tiled 俯视场景。详情及验收见 [v0.33 横版森林](V033-SIDEVIEW-CONTRACT.md)。
