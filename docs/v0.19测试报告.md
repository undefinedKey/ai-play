# v0.19 第一阶段测试报告

基线 v0.18.0，目标为 [第一阶段契约](V019-GAME-FEEL-CONTRACT.md)。本报告记录发布前完成的本地与肥鱼隔离验证；生产版本、精确提交、迁移备份与原 AI 恢复另以发布回执核对，不把计划中的上线检查写成已经完成。

## 实现与回归范围

- 服务端按真实时间推进实际小数坐标，walk 2 格/秒、run 3.5 格/秒，跑步路程耗能为步行两倍；导航目标仍为合法格。途中停止、改道、追击、入口切图、体力耗尽和授权截止均使用实际位置。
- 角色和怪物攻击具有准备、命中复验与恢复，命中只结算一次，迟到、失联、暂停、过期、重启和目标消失不会产生重复伤害。射击朝向取目标主轴。
- 模拟 100ms，旁观合并广播 200ms，浏览器有限预测不超过最近确认后的 250ms。移动与心跳存档合并，实际结算和权限变更仍同步持久化。
- 四方向走跑、攻击和受击使用真实动作阶段；人物、装备、名牌、气泡与镜头同步。拖动、缩放、跟随、复位、全屏、键盘、双指手势与可关闭音效均为只读操作。
- Skill v0.19.0 增加 AI 自选运动模式与当前动作反馈；保留原 16 能力、2000 UTF-16 桌宠上限、主人目标补丁、预算、期限和原身份。极限上下文仅压缩结构 ID 与重复说明，引用按请求隔离，不代替原 AI 选择新目标。

## 实际限制与发布要求

100 观众同机压测验证计算、内存和协议，不代表公网带宽已满足。此次纯 SSE 载荷约 25,203 字节/观众/秒，100 人约需 20.16 Mbps，尚未计协议开销。比 v0.18 同条件记录更高，原因是连续位置与动作状态更频繁；实际公网人数仍受服务器出口限制。

公开像素素材目录从 1,706,988 增至 4,883,313 字节，其中 PNG 453,642、JSON 4,428,591。浏览器承担渲染，低性能设备可减少动态或使用兼容图层。资源实体化、昼夜、共同营地与进一步扩容不在本期。

发布须同步精确 GitHub 提交和版本，再使用既有备份、迁移核验、原子切换、失败回滚流程。上线仍须核对真实服务/资源/Skill 版本、公开只读页面、原身份/授权/预算与主人本地目标配置；仅恢复原先运行的桥。
