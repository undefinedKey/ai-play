## 已验证的行为

- **登录链接**：十分钟有效，数据库仅存摘要，预览不消费，确认后一次性换取会话，重放/过期/无效令牌失败；跨重启保留票据，旧密码账号继续有效。
- **账号权限**：已登录用户只能为自己生成登录链接；成员不能签发管理员 AI 邀请。角色控制令牌不能变成主人会话，不能访问管理 API 或自己扩大活动许可。
- **直接入场**：通过真实 HTTP，从免密码管理员会话签发 AI 邀请，独立 Skill 无浏览器 cookie 兑换，再通过真实 MCP 入场和主动暂停。没有请求网页登录、注册或网页配对接口。
- **领取恢复**：请求前保存设备证明。模拟服务已提交、客户端丢失响应后重试，角色、控制端、截止时间和预算都不重复创建；不同设备重复领取被拒绝。原控制端撤销后不能重兑复活。
- **崩溃恢复**：独立子进程真实在世界数据写入、账号事务提交前退出。重新启动后只清理带邀请标记且没有对应账号的未完成角色，普通角色与已提交角色保留；原邀请码和同一设备能再次领取。
- **边界与保密**：保留 Host、Origin、CSRF、JSON 与请求频率检查；输入失败不消费邀请码；公开旁观快照没有登录令牌、邀请码、设备证明、角色令牌或私人活动目标。
- **Skill 更新**：版本按数字比较，固定官方仓库与提交，校验 Git blob 内容；拒绝路径逃逸、符号链接及超量文件。更新保留服务地址、授权记录和自定义文件，保留备份，替换失败恢复原目录。运行锁阻止同一连接并发升级，Git 工作区不被强制覆盖。
- **更新提示**：有缓存、有限超时，离线不阻止现有连接；同版本不会反复提示；检查与安装明确分开。
- **浏览器**：登录片段立即从 URL 清除、保留配对参数，明确确认后登录；已有会话换账号也需确认；无效链接可返回普通入口。管理员能复制 AI 邀请提示词。手机与桌面布局及主要页面 axe A/AA 自动检查通过。

## 测试边界

更新安装测试使用模拟 GitHub 响应及独立临时 Skill 文件夹，没有覆盖用户真实安装目录。安装旧版 v0.5 的 AI 仍需手动取得一次 v0.6，之后才有更新命令。更新前需停止所有使用该 Skill 的桥；锁只自动覆盖当前状态文件。

没有远程登录用户的 Debian 服务器、签发用户真实管理员登录链接或改变服务器账号。没有实测真实 dsh-pet 模型，也没有验证长期后台运行或完整生产负载。

邀请码中的调用上限由参考 Skill/运行器执行可观测的计数，不代表服务器能测量任意第三方宿主的全部真实模型费用。免密码验证不改变 HTTP 试用环境没有传输加密的事实。
