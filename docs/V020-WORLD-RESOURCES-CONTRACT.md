# v0.20 第二期：可交互荒野、资源循环与昼夜

基线是 v0.19.0 / f7790215807cd2a4c1a0df4497751f59f164a8e7。本契约记录本期全部范围，完成情况以测试与线上回执为准。

## 用户目标

树木、矿点成为有位置与状态的实体，打通采集、制作、补给、探索循环。世界增加昼夜，原 AI 继续自主决定行为。扩大地图，重新布置拥挤场景，环境美术向原创墨线、低饱和土色、手绘荒野方向靠近。通过测试后同步 GitHub 并部署肥鱼。

## 规则与可见结果

- 地图从 24×16 扩为 48×32。保持现有身份与合法物理位置；旧导航合法格不新增障碍。旧营地、入口和活动连接保留。新增松影林缘与苍石山脊作为有限探索目的地，探索抵达不自动采集。
- `shared/resources-layout.js` 是资源位置的共同来源。每个节点有独立 ID、场景、实体位置、交互位置、库存、产量、工具要求与再生时间。画面、服务端距离、资源状态与 AI 观察一致。
- 节点库存全世界共享，一次只保留一个有限预约。采空显示枯竭状态，再生后重新可采；并发和重试不能重复领取。
- 原 AI 显式选择节点、走或跑后，执行器只完成一次最长 120 秒的到达与采集。接近期间用真实连续移动；到达交互格后才开始工作并扣除工作成本。取消、失败、失联、期限结束、场景变化、受击或重启必须有明确结果，不自动换资源或续采。
- 旧 `resource_id:wood|ore` 接口仍使用真实共享营地节点，保留需在附近的条件，不绕过库存和工具规则。
- 斧头、镐及已有农具、装备、仓库、账本共存。徒手营地材料提供工具制作起点；工具消耗与维修有实际成本。野生食材能制成补给，补给恢复真实生命或体力，装备能用于既有探索战斗。
- 制作、使用、修理均由原 AI 分别决定；观众点资源只能查看事实，不能替 AI 执行任何动作。

## 昼夜

持久世界时间采用白昼 300 秒、黄昏 60 秒、夜晚 180 秒、黎明 60 秒。公开当前阶段、世界日、阶段边界与服务时间。重启沿用基准，时钟倒退不得使世界时间后退。昼夜不触发模型逐帧调用。

夜间开始的资源工作体力成本为白昼的 1.2 倍、耗时为 1.25 倍，工作开始时锁定，不在中途额外扣费。月光草只在夜晚与黎明开放。无人旁观时世界照常推进；离线不受昼夜伤害，不自动损毁财产。AI 自己选择是否夜行。

## 画面与观看

原创手绘荒野地表、墨线资源道具、较大的空地和可读道路；营地、林地与矿区具有布局区别。保留各 AI 的独立形象和已完成的四方向动作。地图扩大不等于把所有人物压小：默认镜头保持原观察尺度，可平移、跟随与缩回全图。

资源呈现可采、有人接近、工作中、耗尽、等待再生等真实状态；采集工具和人物动作一致。昼夜使用服务时间与实际阶段，夜间文字、人物和交互仍可读，断线冻结。保留无人物名单、匿名只读、手机触控、键盘、全屏和减少动态效果。

## 验收

1. 规则：节点空间、有限预约、并发竞争、库存与再生、工具耐久和维修、真实到达、途中取消和中断、幂等扣发。
2. 循环：真实 HTTP/MCP 从徒手材料开始，制作工具、采具体树木/矿脉/食材、制作与使用补给/装备、进入探索；证明真实物品流转与成本，不以直接改库存替代链路。
3. 接入：原模型与桌宠有限意图、当前资源/昼夜信息、2000 UTF-16 上限、原消息与合作同意、预算/期限/本地目标补丁保留，旧客户端兼容。
4. 时间：四阶段边界、工作跨阶段、午夜与多周期跳时、重启与回拨、无人旁观、公开当前事实。
5. 迁移：旧角色/合法小数位置/仓库/农田/工具/装备/成长/历史/授权均保留；旧采集中断有凭据。新资源与世界时钟仅按定义初始化，不能伪造旧成果。
6. 美术：桌面 1440×900、手机 390×844 与 390×900 实际截图；白天、夜晚、新扩展区、多人、长文本、加载、断线、素材缺失与只读边界。实际资源位置匹配导航，角色与道具不挤作一团。记录生成来源、真实尺寸、透明度与使用方式。
7. 容量：肥鱼隔离环境 5 个脚本控制端、100 个旁观连接、至少 300 秒实际计时，区分应用和负载客户端，核对实际资源与昼夜传输、无观众世界推进和带宽。脚本负载不冒充原 AI 偏好。
8. 发布：本地回归、真实浏览器及 Linux 精确提交发布门；备份、迁移核验与失败回滚；同步 GitHub 和 v0.20.0 标签，部署肥鱼，完整更新原 Skill，恢复原先运行的桥，核对线上版本和原 AI 的真实回复。

大型基地编辑器、公会、多人 PvP 和新模型托管不在本期；资源循环、美术疏朗化、地图扩展与昼夜均为本期必交付范围。
