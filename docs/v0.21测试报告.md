# v0.21.0 生存循环测试与发布记录

基线 v0.20.0。此版本补上真实篝火、燃料、火把、饱食与黑暗风险，以及树木生命周期和补种。沿用两个 48×32 场景、原 AI 身份和自主选择方式。美术继续使用原创纸墨地表与既有像素角色，属于混合风格，并非已将所有角色与建筑改为《饥荒》的画法。

## 已实现的循环

- 31 个资源节点，其中 23 个树木点位。树木最后一段砍伐掉松果，经历树桩、空地、树苗、幼树、成熟；野生林地自然更新，人工植树空地必须明确种植。营地枯枝每 600 秒恢复一个，作为起步资源；森林才提供较高木材产量。
- 5 处可达宿营地，普通篝火与石围火塘各有材料成本、照明范围和燃料上限。木材、草、松果可添柴，容量不足整体拒绝且不扣材料。火会在离线时继续消耗，熄灭后必须由 AI 再次决定点燃。
- 火把提供携带者个人保护，篝火为同场景范围内角色共享。火边可烤浆果；所有食物有真实饱食价值，满血但饥饿也能进食。
- 600 秒完整昼夜。夜晚暗处先预警和给予 90 秒宽限，再结算伤害；饱食归零也有伤害。无光或饱食归零不能继续休息回血。离线和暂停不补扣个人消耗；倒地沿用营地救援与有限反应保护。
- 接入端收到准备夜晚、饥饿、暗处和燃料风险信息。建火、添柴、料理、吃饭、种树和出行均由原 AI 决定；服务端不会自动续采、补给或给 AI 安排固定日程。

## 规则与真实动作验收

最终 `npm test` 完整执行 748 项：745 通过，0 失败，3 跳过。跳过的是 Windows 不运行的 Linux 发布演练，以及两个已有按需长探针；Linux 演练已在肥鱼隔离环境补跑。完整日志为本地 `artifacts/v021-node-release.log`。

`tests/v021-http.test.js` 通过真实 HTTP/MCP 从起始物资完成：采矿做斧头、砍完指定树取得松果、采草和浆果、补种、走到宿营地、建火、烤制与进食、等待自然熄灭、明确添柴并度过整个夜晚。只有世界时钟受控，没有注入中途库存、位置或生命。另一名身处暗处的角色受到真实伤害，进行中的采集被中断且没有奖励。

新增边界检查覆盖预约竞争、取消、过期、幂等回执、燃料上限、同场景距离、树龄推进、时钟回拨、暂停与重启、个人授权租约，以及树木/物资/身体状态的公开投影。延迟 tick 的行程、休息恢复、伤害和游戏奖励按发生顺序结算：活动先结束可得奖励，先受伤或同刻受伤则中断。

原模型桥与 dsh-pet 桥通过完整动作和未知回执恢复测试；原请求 ID 重用，不重复扣材料或预算。主人要求、消息与合作上下文仍在，真实完整目录的紧凑提示受 2000 UTF-16 上限约束。维持原 16 项能力声明，通过规则版本识别新玩法。

旧经济用例明确使用邻居既存有限火塘与有限木材，通过真实 MCP 添柴，隔离夜间风险后验证零资源旅人的旧交易/修理/农田链；这不是“独力零资源生存”的证明。新版完整生存链由前述 HTTP 用例单独验证。

## 存档与发布保护

独立校验器从备份和升级后 SQLite 比较身份、凭证、授权、预算、外观、库存、账本、农田、工具和装备。旧版只新增默认饱食状态，不赠送火、火把、木材或种子。已有生存存档按实际时间消耗共享燃料，个人火把熄灭并保留剩余燃料，清除旧行程与危险累计；不自动补发奖励、加饱食或离线伤害。

肥鱼隔离目录以 `nobody` 执行发布故障演练：4 项通过；历史、场景、连续位置、资源与生存 SQLite 迁移：14 项通过。包括新生存校验器缺失/失败、发布文件缺失时拒绝切换，以及回滚成功后才恢复原桥。演练未访问生产数据库。

## 发布验收状态

最终源码在肥鱼隔离进程运行 600.01 秒，5 个脚本控制端和 100 个公开 SSE 连接。不是模型行为评价，没有操作生产角色或数据库。共 165 个动作、252,900 帧全部重建，动作失败和旁观错误均为 0；五人保持在线存活，完成白昼、黄昏、夜晚、黎明到第二天。夜间五人共享真实火光，火曾自然烧尽并由明确动作补燃，物资实际扣除。

## 浏览器与素材验收

Chromium 在 1440×900、390×844、390×900 实际渲染，覆盖镜头、独立地图、五人同格、长名、键盘、减少动态、断线冻结、图集缺失和兼容画布。20 项相关浏览器回归首次 19 通过；发现 WebGL 图层销毁后夜幕重绘访问旧纹理，修复后该项与 4 项新生存用例复测全部通过，20 项当前覆盖均通过。树苗旁透明人物点击框的遮挡问题也通过真实点击验证修复，没有使用强制点击绕过。

新用例通过 MCP 真实采草、走到火点、建火和添柴，校对公开燃料、夜间画布变化和跨场景隔离；另完整砍树得松果、种树，展示树桩、幼苗、幼树到成熟的阶段。旁观点击没有写操作，三个尺寸 Axe 检查无违例，无常驻人物列表与横向溢出。根代理实际查看桌面、手机火光和森林全景截图。

public/dist 的 95 张引用 PNG 校验通过，地图与发布静态检查通过。视觉记录 `artifacts/v021-ui-evidence.json` 通过 frontend-design-direction 检查器；加载、空场、错误、部分素材、成功与只读权限状态均有实际浏览器证据。WebGL 故障用例补充页面错误断言后另行复测 1/1 通过。沿用无额外服务端渲染进程的 Web 画布方案。实体手机、Safari 与 Firefox 未实测。

## 正式发布的验收方式

本报告随发布候选提交。正式切换前，肥鱼重新执行测试、构建、静态检查与短时实时基准，再停止原桥并备份数据库。精确提交部署后需通过线上版本、独立存档迁移验证，完整更新原 Skill，保留身份、原授权、调用预算、截止时间、本地配置与两处主人目标补丁，再恢复原来运行的桥。

发布完成还需检查原 AI 的新版本健康心跳和真实模型回复，以及三种尺寸下的广场、冒险、农作页。发布日志、原桥验证与线上浏览器结果分别保存在本地 `artifacts/feiyu-orchestrator-v0.21.0.log`、`artifacts/feiyu-runtime-v0.21.0.json`、`artifacts/feiyu-release-v0.21.0.json`；正式线上版本以 `/api/health` 为准。
