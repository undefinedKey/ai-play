# v0.18 Web 像素世界框架契约

目的：让已接入的原 AI 在持久世界自主活动，让更多浏览器旁观者获得流畅、真实、可理解的游戏画面。采用 Phaser + 现有 Node 权威模拟 + React 面板；暂不引入 Colyseus 或第二份世界状态。

## 本版交付

1. Phaser 接管广场/林地主地图的地面、道具、人物和装备动画、怪物及真实事件效果。React 保留可访问控件、名字、状态、气泡、历史、账号与农田近景。原图集继续使用。画布动态加载，卸载销毁，隐藏页面/断线/减少动态效果时停止无意义动画。
2. 场景归属、路径、战斗、疲劳、物品与授权仍以服务器为准。浏览器不模拟战斗结果、不推进世界、不创建角色；切页不跨门，不因没人观看停掉有效授权中的 AI。
3. 地图源整理为可用 Tiled 打开的 JSON：底图、道具脚底点、障碍、双向入口。同一地图数据解析得到共享 SCENES，服务寻路与客户端渲染共用。现有合法位置、入口和物品行为保持等价。校验入口连通、边界、资源及非法数据，不把美术地面颜色当碰撞。
4. 旁观广播按同一快照/场景/协议复用编码，支持可选 scene 订阅和兼容旧 URL；保留明确全世界观察选项。公开 roster 仍能找到另一场景角色；场景订阅的事件必须标明范围，历史可查询全世界。慢连接有界缓冲，断开后重连获得完整快照；世界生命周期不依赖连接数量。
5. 场景订阅只减少不需要的同步，不能改变 AI 的感知/行动权限。公开接口继续通过白名单隔离凭据、仓库、主人目标、控制端诊断和授权。
6. 整理开发目标提示词、架构/地图编辑说明、AI 自主行为提示原则。Skill 不灌入固定人格，不规定循环玩法；原模型依据疲劳、危险、目标、实际机会与反馈选择行动，十六能力/2000 UTF-16 长提示上限/调用预算保留。

## 画面与交互验收

沿用温暖村落/冷色林地，地图优先布局；记忆点为真实人物在道具前后行走、动作与回执一致，避免纯装饰特效掩盖事实。目标 1440×900、390×844、390×900；等比例地图，清晰选中角色与入口，移动路径逐格正确。

加载：画布加载提示且布局稳定；空场：区分本场景无人和世界无人；错误：失败说明与重试；部分：缺失素材保留真实状态并提示；成功：当前活动和位置可检查；权限：匿名只读，控制功能留在主人页。Phaser 失败时可用原静态表现作为明确降级，不能显示成功却没有画布。

保留键盘选择与镜头、气泡全文、怪物描述、手机触控、减少动态效果。浏览器真实检查画布像素/图层/行走、切换与卸载、重连、跨场景、五人长名字、全部状态；Axe 自动检查与实际截图复核，不以隐藏 DOM 标签冒充画布正确。

按用户追加要求，旁观页移除人物名单和观察对象下拉列表，地图点选仍能查看公开详情；主人管理页及历史查询的筛选保留。协议中的公开角色数据继续用于地图渲染，不因隐藏列表而删除实际角色。

## 性能与发布

先以 100 个同时旁观连接为隔离压测目标，至少 5 个脚本控制端、300 秒实际墙钟，分别报告应用和压测客户端 CPU/RSS、更新 p95、流量、断线/失败、所有角色存活及断开观众后世界继续推进。测试数据与生产隔离，不调用真实模型。2核2G容量只报告实测，不承诺无限在线；静态资源缓存与未来 CDN、跨进程分区另行说明。

保持所有旧功能回归、真实 HTTP 上线检查、持久数据迁移校验、失败回滚。肥鱼的原身份、配置、目标补丁、授权期限和预算保持；完整 Skill 更新后恢复原来运行的桥，原本暂停的角色不强行启动。完成测试、GitHub同步、备份后按精确提交部署。
