## 已验证的功能路径

服务端新增十六项合作用例，与相关后端回归共 **155/155 通过**。覆盖本人选择分工、指定对象响应、拒绝与退出、两方私账、原子备餐、托管退款不刷个人目标、暂停/失联/磁盘重启后双人复核、撤销与召回、探索待选期间关系管理、邀请/历史上限、期限和旧回复。

真实 HTTP/MCP 三项集成通过：

1. 供菜者与厨师分别同意，明确交菜和烹饪，双方各得到一碗汤。重复动作回执不重复扣发，两份私账与实际变化一致。
2. 模拟每次决策间隔四十秒的侦察与清怪，护卫为二十级且一击击败野猪，仍可按先后分工完成。未参战的侦察员没有额外金币。
3. 两位成员主人与第三方管理员账号通过真实 HTTP 登录读取快照，另有角色 MCP 令牌鉴权。未接受对象和私有拒绝回复不进入第三方或公开旁观数据。

旁观专项四项通过，另二十一项相关界面回归通过。三视口包含共同备餐、双人复核与退出、邀请超时、巡查、空场、五人同格、长同名、个人目标及游戏并存、断线、键盘、axe 和只读操作。原有公开投影额外检查嵌套对象注入：未知私人键与伪装成标量的对象不被公开。

完整浏览器最终 **61/61 通过**，无失败、无 flaky、无跳过，耗时 5.2 分钟。初轮发现测试自身快进时钟与 HTTP 校时竞争；仅修正测试同步方式，专项连续三次通过后重跑完整集。初轮日志保留，不将初轮称为全通过。

扩展权限检查发现旧小组邀请和暂停原因会进入第三方主人快照。本版修复 `snapshotFor` 的事件投影：私人控制信息仅本人，定向邀请按实际参与者，其余复用公开字段白名单；公开事件的广播收件人不等于私人信息权限。真实 HTTP 三主人/MCP 回归及相关测试 **24/24 通过**；修正后再跑受影响浏览器 **26/26 通过**。匿名旁观、主人 HTTP 与主人 SSE 继续保留各自权限边界。

迁移验收新增 30 种真实重启状态/篡改检查，并保留旧版 37 种检查。验证既有探索、目标、托管、阶段来源与同意绑定；到期退款不刷新收集目标，容量极限只产生一笔待退。Debian 隔离发布故障演练由 `nobody` 运行，三项 Python 测试通过，其中包含八种 Bash 发布失败路径；使用测试服务/路径和 SQLite 数据，未访问生产数据。

Skill/运行器最终专项涉及十六个测试文件，**180 通过、0 失败、1 个按条件跳过的长恢复探针**。新增合作 26 项通过：两种原运行器入口完成备餐，双邀请按四十秒决策轮换且只确认展示过的事件，旧短 ID 不跨请求复用，完整独立升级包含新 helper/reference，能力准确上报为十六项。模型回复为测试替身，用于验证原运行器路径，不表示生产 AI 已选择合作。
