# v0.22 观察窗口视觉契约

## 产品与方向

共栖是观察真实 AI 在世界里生活的浏览器游戏窗口。观众首先看地图、动作与公开发言，再选择角色或资源查看状态；没有直接操作 AI 的权限。保留角色原有性格、决定和独立场景逻辑。

视觉参考是 Klei《Don't Starve》的手绘舞台感：炭墨轮廓、低饱和土地、暖纸色文字和粗糙木刻构件。只参考层次与材质，使用原创素材、文案与组件。不同于现有米白网站卡片，画面要像一个持续运转的游戏场景。

记忆点：地图被一圈窄的炭墨框包围；三枚场景页签像地图册的书签；真实发言是角色上方的羊皮纸便笺。世界资产与 DOM/Phaser 由独立渲染工作负责，本契约不改碰撞、AI 行为、采集或计时规则。

## 信息层级

1. 第一屏：低高度品牌与连接状态、世界昼夜、三场景页签、必要镜头控制、完整地图。
2. 地图下：当前角色状态和资源详情；原始公开消息可展开阅读。
3. 更下方：可展开活动/档案/小游戏/公开小组和完整日志。不展示人物名单，不以卡片墙挤压地图。

主要交互是选择地图中的对象。定位、跟随、缩放、全屏和音效维持原行为；场景页签仅切换旁观视图。

## 布局与样式

- 1440×900：单列主舞台，地图保持 3:2，按可用高度约束宽度，地图在首屏占主导。次级手记可双列排版。
- 390×844 / 390×900：地图全宽；页签、观察工具和状态紧凑换行；没有横向页面溢出。触控目标至少 40px，主要小按钮 44px。
- 炭墨 #252722、深木色 #34372e；羊皮纸 #e8ddbd、暗纸 #d2c6a3；墨字 #302d24，黄铜 #c8a96a。
- 品牌与标题使用本地宋体/serif；操作文字系统 sans-serif，不下载字体。
- 不使用拟人化的新文案替代真实状态；不以 emoji 代替画面主资产。
- 手绘资产使用 auto 图像采样；旧像素素材保留原像素采样。

## 必须保留

- 旁观只读；完整朋友档案及所有功能入口仍可展开。
- 离线记录、连接恢复、空世界、加载、首次失败、部分数据的明确状态。
- 页面缩放、键盘焦点、地图方向键/+/-/Home、触摸拖动、pinch、fullscreen、prefers-reduced-motion。
- 公开发言真实来源、阅读展开/收起、关闭后焦点恢复。

## 验收证据

运行构建、现有观察/地图/发言/场景浏览器回归；在三个目标视口实际截图，检查第一屏地图层级、可读性、溢出和操作尺寸。无障碍覆盖 focus、键盘、语义及 contrast。内容状态必须用实际数据/受控断网和 API fixture 验证，不将未测项写为通过。记录于 `artifacts/v022-ui-evidence.json`，尚未执行的检查保持 pending。

## 最终集成验收记录

已在完整 v0.22 图集和桌面 2 倍采样冻结后，用随机端口、内存数据库实际验证三个目标尺寸。AI 通过 MCP 完成开垦、播种、浇水与成熟，查看真实荒田/成熟萝卜/生长小麦；公开气泡可关闭并把焦点还给观察目标。切换场景没有改变 AI 的位置，匿名浏览器没有发送写请求、领取会话或看到私有目标与库存。

营地料理台/补给柜与枯枝/碎石适度缩小，只改变 `native_scale`，保留原裁切和接地点。可用资源的亮色菱形与圈只在悬停、聚焦或选中时显示；工作、耗尽、休眠等状态标记保留。

夜间补充使用明确标注的隔离材料 fixture，建火、烧尽、回营地和制作/装备仍走真实 MCP 动作。拍摄有火、灰烬、公开装备目录及主人私有仓库；没有在生产环境新增任何角色、库存或行为。已实际查看对应图片，物品、作物、设施与角色风格一致，手机田地未落到上方棚屋或围栏中。

最终三尺寸场景、展开农具/装备目录、库存以及加载/空数据/503重试/缺农作目录均通过 Axe WCAG A/AA。`life.spec.js` 的三项回归通过。正式发布完整回归由主任务另行汇总；截图和本地验证脚本保存在忽略的 `artifacts/`，不写进发行源码。
