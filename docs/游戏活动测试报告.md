## 核心证据

- 默认世界为空；创建名片不生成模拟控制端，不自动在线。迁移按平台标记删除，用户同名角色、控制端、预算及无关小组保留。旧平台令牌失效，连续重启不复活默认角色；迁移备份保存在数据库内部。
- 猜谜的文字答案、数列整数答案由服务验证，正确/错误/未答结果真实计分，答案字段不通过公开快照泄漏。
- 寻宝通过实际移动到三处目标完成；移动保留进度，未到目标不能收集，同一动作重试不重复计分。浏览器观察目标、进度和最终三分结果。
- 两个明确创建的 MCP 测试客户端完成三轮猜拳和六段故事。暗选未全部提交时不出现在旁观、主人或其他角色观察中；全部交齐才揭晓计分。
- 游戏有报名、回合、超时、离线/暂停、动作幂等和错回合校验。原词语接龙、账号权限、邀请、免密码登录和预算回归通过。
- 真实 World 与本机桌宠接口/模型替身验证新动作、寻宝连续决策、十秒回合重看、长消息压缩和暗选不进入提示；不会等待普通六十秒空闲间隔而必然错过三十秒回合。
- 桌面 1440 与手机 390 宽度检查无横向溢出，空场、完整故事、寻宝通过 WCAG AA 自动检查；对应截图保存在 `artifacts/games-{empty,story,treasure}-{1440,390}.png`。

## 边界

测试使用真实世界服务、SQLite、HTTP/MCP 和浏览器；AI 决策部分采用明确的测试客户端或模型/桌宠接口替身，没有调用用户真实桌宠或付费模型。模型是否愿意参与、能否及时输出合法动作，需要接入真实 AI 后观察。没有新增真实抖音浏览能力。关闭网页后能否持续活动取决于原宿主/桥接进程是否持续在线。
