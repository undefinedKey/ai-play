# v0.36 广场空间与真实设施

2026-11-05，用户确认实施生活广场摆放方案。沿用48×32世界与原创Q版像素风，完成现有公共设施的空间重排和实际服务对齐；共同建设不在范围内。家园室内的家具、鱼缸、陈列品与留言仍由原房主决定，不自动整理。

## 空间与设施

- 中央为会客空地，边缘放公告板和景观，留出完整的停留、穿行空间。
- 北侧住宅入口、西北池岸、西侧阅读与游戏区、东侧生活服务街、南侧野餐和舞台，用可通行的环路与支路串联。
- 阅读、游戏、补给、料理、制作维护、农作办理、集市、家园与远行入口的实体外观、占地、服务站位及门前道路对齐。不让房子画在一个地方、服务却在别处执行。
- 林地与横版旅程有各自真实的入口关系。农作办理点延续原有田地服务，暂不建立新的独立farm场景，也不把私人田块显示成公共中心地面。
- 一份可独立安装的布局契约定义公共设施、道路与位置；地图生成和校验、世界规则、Skill与客户端都使用该事实来源。保留设施/资源稳定ID，已有交易条款、配方、库存与结算方式不因搬位置改变。
- 设施前有可站立位置，建筑门面朝路，座位朝向其服务对象；树冠、屋顶、标识不得挡住主要操作点。地面不画概念方案的分区边框。
- 建筑、人物、桌椅与路牌使用一致的比例；远景以少量区域名称帮助辨认，具体设施说明按靠近、悬停或点选显示。旁观UI无角色操作、常驻人物列表或黄色角色选择框。

## AI 自主行为

服务端根据AI明确提交的动作校验真实站位与条件。地点不符时返回实际原因与目标位置，不把失败动作静默替换为旅行、采购或补给。有限移动仅来自原有明确移动/前往/访问动作；到达不自动开始下一个行为。

Skill通过服务器规则读取地点与可走候选，保持原模型、身份、目标、消息和已有授权。位置更新不重写兴趣，不添加默认角色、不强制活动路线、不自动续做。纯景观不能假装提供尚未实现的功能；夜间光照仍以世界真实规则为准。

## 存档迁移

1. 保存原角色ID、外观种子、衣橱、库存、工具、装备、田地、成长、授权、目标、控制配置和家园内容。
2. 对已有广场位置：仍合法就保留；与新障碍冲突时才按可验证的确定性规则修到最近合法点，并记录布局迁移事实。
3. 不因旁观镜头或地图更新改变其他场景的位置，不重建家园，不挪动原室内家具或室内实际位置。
4. 重启取消旧路线与未完成的瞬时活动，不沿旧路穿过新建筑，不凭迁移发放物品、代替同意或继续新工作。
5. 旧地图共享资源/火塘采用同ID的实际新地点；保存储量、再生时间、内容与燃料等可保留事实，任何必要变化必须独立校验，不能重置刷资源。
