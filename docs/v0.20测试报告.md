# v0.20.0 第二期测试与发布记录

基线为 v0.19.0；本期交付可交互资源、采集制作补给循环、服务端昼夜和 48×32 荒野地图。记录日期：2026-10-31。发布状态以最后一节和线上版本为准。

## 已完成的功能与边界

- 两个地图从 24×16 扩为 48×32，面积为原来四倍；旧角色合法位置、营地、入口和导航通路保留。林缘与山脊为新增探索目的地，抵达不自动采集。
- 9 个共享资源节点具有真实位置、库存、预约、采集时间和再生。支持营地徒手材料、树木、矿脉、浆果和夜间月光草。一次意图只执行一次有限的到达与采集，不自动循环。
- 斧头和镐有制作、三级耐久、维修升级；浆果和草药进入口粮/炖菜配方，恢复真实体力或生命，装备制作仍连接既有战斗系统。
- 600 秒世界周期：白昼 300、黄昏 60、夜晚 180、黎明 60 秒。夜间开工锁定更高耗时和体力成本，重启不重置世界时间。AI 自行选择行动，不因旁观点击而改变。
- 原创纸墨地表、树木、矿石、灌木与更疏朗道路；保留现有 Pixelbolt 角色身份、四方向动作及部分建筑/怪物。属于混合美术升级，并非已将全部角色动画改成手绘风。
- 默认镜头 200% 保持人物可见尺寸；全景 100%，支持拖动、跟随和全屏。无常驻人物名单；资源详情只读。

## 规则、接口与迁移

`npm test` 完整执行：680 项，677 通过、0 失败、3 跳过。跳过的是 Windows 不执行的 Linux 发布故障演练，以及两个已有的按需长时间恢复/模型续租探针；Linux 演练已另在肥鱼隔离环境执行。

新测试覆盖节点预约竞争、真实接近与开工、幂等扣发、库存再生、耐久与维修、取消/暂停/失联/受击/死亡/重启、夜间成本锁定、时钟回拨与跨多个周期。奔跑途中耗尽和恰在路径段末耗尽均验证只中断一次；营地回体不能擅自续采。

`tests/v020-http.test.js` 通过真实 HTTP/MCP 从初始材料走完制作斧镐、采树/矿/食材、制作并使用补给、装备和探索，没有直接改库存或位置跳步骤。验证生命 38→40、体力 22.93→40.93、斧镐耐久 12→11，公开视图不泄漏私人仓库、账本、主人目标和运行凭据。

肥鱼以 `nobody` 在独立目录运行：发布故障演练 3 项通过（涵盖准备失败、切换失败和进程状态不确定等分支），历史/场景/连续位置/资源迁移 6 项通过，未访问生产数据库。独立迁移校验器核对原身份、授权期限、预算、库存、装备、账本、农田和旧工具保留，只允许新增两件未拥有、耐久 0 的斧镐默认状态；资源不能超额再生，时钟不能倒退，旧预约必须清除。

地图、素材和发布静态检查通过：两个场景全部可走格可达，旧合法格保留，所有资源交互点可达，入口互相连接；public/dist 各校验 91 张实际引用 PNG。

## 浏览器验收

桌面 1440×900、手机视口 390×844 与 390×900 使用 Chromium 实际渲染，覆盖白天/夜晚、真实砍树和采矿、枯竭、长名字与多人、只读资源详情、加载/空场/断线/兼容图层/素材缺失、镜头与减少动态效果。

完整回归首次执行 87 项：82 通过，5 项是旧 24×16、旧资源 DOM、旧采集文案、同节点多人同时开工及旧空场提示位置的断言。按新契约修订后，三个受影响文件复测 15/15 通过；87 项用例的最新覆盖全部通过，并非声称首次全套零失败。共享资源测试明确验证同节点 1 人成功、4 人被 RESOURCE_BUSY 拒绝且库存不变，选择另一节点后可独立工作。

视觉证据保存在本地 `artifacts/v020-ui-evidence.json` 和对应截图，frontend-design-direction 检查器已通过。实体手机、Safari 和 Firefox 未在本期实测。

## 发布验证方式

本报告记录发布前验收。GitHub 主分支及 v0.20.0 标签采用同一代码提交，肥鱼按精确提交部署。发布流程在停旧服务前执行 Node 全套、构建和隔离检查；切换时备份 SQLite 与配置，核验迁移和公开接口，完整更新原 Skill。仅恢复此前活动的原桥，不新建身份、不增加预算或延长授权。

最终执行回执保存在本地 `artifacts/feiyu-orchestrator-v0.20.0.log`、`feiyu-release-v0.20.0.log`、`feiyu-release-v0.20.0.json` 与 `feiyu-runtime-v0.20.0.json`，分别记录服务/Skill 完成、迁移、线上九种视图和原桥状态。实际发布是否完成须同时核对终态、Git 提交和公开 `/api/health` 版本；仅构建或上传不算上线。
