# v0.20 荒野、资源与昼夜 UI 契约

目标是让观众进入一个有留白、能辨方向和资源状态的共享荒野。现有地图拥挤且所有场景被缩进一张画面；本期实际扩展为 48×32（1536×1024 原生单位），默认镜头看约 24×16 的局部，保留原角色身体尺寸、身份和行动决定权。

视觉方向为墨线勾边、低饱和土黄/灰绿、纸面和剪纸轮廓。原创生成地表只包含可走的土地纹理；树木、矿石和设施是独立对象，按真实脚底遮挡。不会复制《饥荒》的角色或地图，也不会把静态图上的树冒充可采资源。保留角色 Pixelbolt 动作与身份，环境可使用原创手绘纹理。

## 地图与层次

- 老 24×16 范围内所有合法格保持可走；核心营地 (11,8) 和场景入口不动。旧建筑和密集树木疏散到扩展区，营地道路、开放草地、远端林区和矿区有明显距离。
- 默认镜头 200%，拖动到新区域；全世界概览 100%。复位回到营地局部，单独提供全景入口；跟随、手动退出跟随、跨场景提示、全屏和触控沿用真实位置。
- 地图是旁观首屏主体。精简介绍与外围面板，资源详情只在点选后出现；没有人物名单。选中资源不能代替 AI 采集、移动或消耗物品。
- 名字、气泡、资源点击区、人物和 Phaser 图层共用地图尺寸与镜头变换。生成地表不决定碰撞；Tiled 脚底占地是唯一静态阻挡。

## 权威资源与时间

- 顶层 `resources.nodes` 按 id/scene_id/position 呈现；库存 stock、预约 reservation、regrow_at 和 available 来自服务器。
- 有库存、正在工作、耗尽等待恢复、阶段不可用有不同轮廓/标记。树木耗尽显树桩，矿点变空石，灌木/草药减去收获状态；倒计时到零只显示等待确认，绝不提前补资源。
- `life.gathering.phase=approaching` 显示前往，`working` 才显示劳动。点选详情显示资源名、剩余量、工具需求、实际工作者与恢复状态，不公开私有库存或主人要求。
- `day_cycle.phase` 控制 day/dusk/night/dawn；夜色影响世界，不降低名字和操作控件可读性。不按本地时钟擅自跳阶段，断线冻结最近服务状态。夜间成本说明来自服务规则。

## 可验收状态

| 状态 | 触发 | 可见反馈与下一步 |
| --- | --- | --- |
| 载入 | 场景/手绘素材未完成 | 保留地图尺寸，载入提示，不出现假居民 |
| 空场 | 无AI或无该场景资源 | 解释当前场景状态，可移动镜头或切图 |
| 错误 | 纹理/网络失败 | 兼容图层或最后状态，允许重试，不假装实时 |
| 部分 | 单个素材缺失/旧服务无资源字段 | 保留可用对象和真实位置，明确资源信息不可用 |
| 正常 | 收到权威资源和阶段 | 可读的实体状态、只读点选详情和真实昼夜 |
| 权限 | 匿名旁观 | 只有公开信息；任何资源点选/镜头操作不发送写请求 |

目标视口 1440×900、390×844、390×900；检查长中文、五人同格、夜晚、耗尽、工作中、断线、减少动态、键盘可聚焦与关闭详情、至少40px触控控件、无横向溢出、Axe对比度。保留真实 canvas 截图与像素检查，原生地图可到达扩展区；检查全景与默认视图的人物尺寸区别，不能只把图标缩小冒充扩图。

证据写入 `artifacts/v020-ui-evidence.json`，按 frontend-design-direction 检查器验收。实体手机和未运行的浏览器内核须明确列为未测，不用模拟指针冒充硬件实测。

## 已执行验收（2026-10-31）

- 原生 1536×1024 canvas；默认营地 200% 与全景 100% 的身体宽度比实测 2:1。旧合法格全量回归、两地图不同道路、水岸顶点仍在真实阻挡区，25 项 UI/geometry Node 测试通过。public/dist 的 91 张引用 PNG 与图集边界检查通过。
- 新荒野 4 项浏览器测试全部通过：真实斧头采集前往/工作/耗尽树桩/再生；真实拾石制作镐、穿场景入口赴山脊采矿；阶段改变、断线冻结、缺素材与兼容图层；匿名只读点选不发送写请求。Axe、三视口及长中文检查通过。
- 完整浏览器 87 项首轮 82 通过，5 项旧地图尺寸/旧采集文案/旧共享资源假设失败。按新契约修改测试后相关三文件 15 项复测全通过；保留原五人选择、巡逻、取消/暂停/断线等覆盖，并新增同节点 RESOURCE_BUSY 无额外库存变化与不同节点同时工作的断言。这是完整运行加定向复测的合计覆盖，并非一次全套全绿。
- 实际查看昼/夜三视口、工作树、耗尽树桩、矿脉工作、断线、部分素材缺失及兼容图层截图。根据画面修复了近景点击区过大拦截邻居、空场说明隐藏、兼容重试样式误染资源按钮；淡化地表墨线，水面改为不规则岸线。所有改动在最终构建上复测。
- 完整证据 `artifacts/v020-ui-evidence.json` 已通过 frontend-design-direction checker；最终新4项 `v020-wilderness-final.log`，最后回归 `v020-browser-regression.log`。真实图：`v020-wilderness-overview.png`、`v020-tree-working.png`、`v020-tree-depleted.png`、`v020-quarry-working.png`、`v020-night-{1440x900,390x844,390x900}.png`。

限制：测试使用 Chromium 与模拟手机视口，没有实测实体手机、Safari/Firefox或声音硬件。环境为原创手绘墨线素材，角色/怪物/远处旧建筑保留 Pixelbolt，属于明确的混合风格；不包含动态光照遮挡或战争迷雾。
