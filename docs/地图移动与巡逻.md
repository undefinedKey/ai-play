# 地图移动与怪物巡逻（v0.8.2）

## 地图尺寸与合法移动

服务端的 `server/spatial.js` 是地图尺寸与步长的统一来源，目前为 24×16 格、每次最多 3 格曼哈顿距离，即 `|Δx| + |Δy| <= 3`。坐标是整数，范围为 x=0…23、y=0…15。

`get_rules` 的 `room`、`adventure.map` 和公开冒险快照使用相同尺寸。每次 `observe` 还提供：

```json
{"movement":{"map":{"width":24,"height":16},"max_step":3,"candidates":[{"x":12,"y":8},{"x":11,"y":9}]}}
```

示例只展示部分候选；实际会根据角色当前位置计算最多 8 个合法、去重且非原地的落点。候选只是帮助选择，不限制其他合法坐标。直接客户端提交越界、非整数或超步长坐标时，服务端继续拒绝，并在拒绝详情中提供当前移动规则与候选。

## Skill 与持续桥

新版提示给出实际尺寸、步长与合法候选。原 AI 选择目标后，持续桥在提交新的 `move` 前再次观察位置，避免模型思考期间角色已经沿冒险计划移动造成坐标过期。

如果整数目标越界，先截到地图边界；如果超过步长，再按所选方向的横纵比例分配合法步数。不会改变方向去另一个地点，不会自动续走到远处，也不会把非法类型或非整数输出当成合法动作。是否继续前进由下次原 AI 决定。

调整发生在首次保存待提交动作之前，重试复用原动作 ID 和原落点。动作确认后反馈包含 `MOVE_ADJUSTED`、请求位置与实际落点，不能把合法的一小步说成已到达最初目标。未知地图尺寸时不猜测；旧服务可使用其 `rules.room` 和 `max_move` 提供的信息。

现有 AI 需更新本仓库 Skill 到 v0.8.2 并重启桥，保留身份、连接和授权预算。移动辅助文件与源码一起通过正常更新流程分发，不修改外部 dsh-pet 安装，也不依赖更新后重施补丁。

## 怪物巡逻

怪物的 `behavior` 增加 `patrolling`。公开规则及怪物记录提供 `patrol_radius: 2`、`patrol_interval_ms: 2000`。

- 没有目标时沿固定小范围路线巡逻，出生点周围曼哈顿 2 格内，每 2 秒最多走 1 格。
- 每秒先检查附近目标，发现冒险者后切换追击；追击、攻击与巡逻共用同一步进，不叠加移动或伤害。
- 脱战先返回出生点并恢复生命、清除伤害贡献，再恢复巡逻。死亡后等待复活，房间暂停时不推进。
- 所有路径都受地图边界和营地安全区限制。未开启冒险的广场角色仍不会受到攻击。
- 没有 AI 或没有旁观者时也巡逻。普通巡逻只更新快照，不产生逐步战斗事件或触发模型调用。

旁观地图按服务端尺寸投影角色与怪物，并对无效显示坐标做保护；这不替代服务端实际坐标校验。已有旧存档的异常角色位置在重启时修复到边界内，身份和成长保留，原计划按既有重启规则停止。

## 验证

自动化验证覆盖所有地图格的合法候选、第三方非法移动拒绝、旧坐标恢复、模型移动调整与幂等重试、慢模型位置更新、提示长度、长时间无人巡逻、追击与归位切换、暂停/复活，以及真实 HTTP/MCP/SSE 旁观。模型响应使用测试替身；不将这些测试视为真实模型长期游玩质量的证明。
