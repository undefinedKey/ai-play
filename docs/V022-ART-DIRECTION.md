# v0.22 美术方向与实景验收

## 目标与范围

把现有 AI 广场、冒险和农场统一成原创的怪诞手绘生存世界。参考《饥荒》的粗墨轮廓、扭斜形状、平面纸片感和留白组织，不复制其人物、怪物、建筑或界面原图。完成范围包括所有实际可见的人物、怪物、建筑、资源、农田、手持装备、物品图标和界面；只换地面、加褐色滤镜或修改宣传文字不算完成。

本轮只改变表达。AI 的身份和自主决策、资源数量与阶段、场景位置与碰撞、工具耐久、战斗结果、昼夜和火光都仍由既有真实状态驱动。旁观者切换地图不能移动 AI。

## 统一画法

### 轮廓、形状与颜色

- 外轮廓使用深褐黑，粗细略有变化，形状闭合、缩小后仍能辨认。内部结构线比外轮廓轻，不给所有表面铺满交叉排线。
- 每个主体优先用 2—4 个大的明暗色面表达体积。排线集中在树干背面、屋檐、头发、衣褶和工具接缝等局部。
- 允许歪斜、夸张和不对称：细长腿、偏大的头、尖翘发梢、弯曲树干、歪屋顶。避免统一正圆、等距直线与光滑塑料体积。
- 建议基色为墨褐 `#201b18`、旧纸 `#d8c39a`、灰橄榄 `#616343`、木褐 `#805b3e`、骨白 `#e8d8b0`；锈红、苔绿和暖橙只作少量识别色。具体取色可调整，但不能重新出现一组明亮糖果色像素资产。
- 保持轻俯视地面与直立纸片物体的共同视角。所有物体的地面接触点与阴影方向一致，不能像贴在空中的图标。

### 人物、怪物与动作

- 保留 `wanderer_1` 至 `wanderer_8` 和现有 appearance 映射。换画面不能让服务器重抽身份或替 AI 定义性格。
- 8 个形象通过头发、帽饰、外套、身形或轮廓区分，不仅换衣服颜色；默认镜头下至少能凭轮廓认出不同形象。
- 人物采用较大头部、窄身和细肢的夸张比例；脸部用少量强对比线条表达。不得直接重画 Wilson 等既有角色。
- 3 种怪物的大小、攻击距离表现和脚底位置仍符合真实实体。美术夸张不能遮住整片道路或暗示不存在的攻击范围。
- `idle`、`walk`、`run`、`attack`、`hurt`、`till`、`plant`、`water`、`harvest`、`craft`、`repair`、`upgrade`、`gather`、`cook`、`eat`、`rest`、`tired` 的显示不能退化成同一张静态图。优先保证走跑、攻击、受击、休息和农具动作有明确姿态差异。
- east / north / south 动作键以及 west 镜像必须继续有效。手、武器、农具、饰品与人物朝向对应；工具不能漂浮、穿脸或始终横在胸前。

### 地面、摆放与生长

- 地面保持低对比、低细节密度；小草和石子按小片聚集，留出完整安静区域。缩略图看不到均匀噪点盖住整个地图。
- 道路、入口、营地、建筑前场和资源群之间留出明显空间。对象形成有目的的小组，不能平均铺满地图。
- 树根、矿点、井、门户等足点遵守实际位置和碰撞轮廓；不能通过缩小碰撞或移动足点来迁就图片。
- 资源树的树桩、树苗、幼树和成熟树应有明确造型差异，不能只把一棵成熟树缩小。装饰枯木与可采集活树要能区分。
- 田地用不规则泥土边缘、平行但略有差异的垄沟和实际作物表达。未开垦、已开垦、播种、生长、成熟各阶段可辨；不要用一张固定丰收背景掩盖真实阶段。
- 夜色与火光依据服务端状态。灭火显示灰烬或冷火塘，不能留住贴图中的常亮火焰。

### 界面与观察体验

- 主要视觉面积留给世界。桌面首屏有完整主要观察区，常用切图、缩放和跟随按钮可找到；不恢复用户明确不需要的人物列表。
- 主框架使用深墨色与简洁手绘边缘。小型羊皮纸标签、对话气泡、仓库和制作面板清楚易读；不要在正文文字后铺高频脏纹理。
- 常驻世界标记要克制。详细数量、动作和资源信息可在选中或悬停时展开，避免每个资源都被大亮框压住。
- 名字、气泡和血条跟随实际实体。多条碎碎念不遮住整个营地，不能出现无对象的悬空气泡。
- 窄屏保留地图可观察性与触摸操作，不将整个视图挤成一列大卡片。普通文字和图标遵守原有可访问性要求。

## 图集与渲染交付约束

- 使用 `manifest.render_style = 'ink'` 声明新风格；高分辨率纹理由 `native_scale` 映射到既有逻辑世界尺度。图片像素更多不等于世界物体自动变大。
- 新图集使用真实透明 alpha。脚底、接地边缘和附着点都要核对；不能用白底或棋盘格假装透明。
- 使用 `anchor_mode = 'source'` 与 source 像素 `anchor` / 每帧 `frame.anchor` 时，明确锚点契约。四向帧切换后，脚底不能跳动；头像、武器与人物仍共用正确附着关系。
- 图集各单元留出足够透明间隔，不裁掉发梢、工具、树冠、火焰，也不把邻近单元采进来。看一次原始透明图集，再看默认镜头和放大镜头。
- 单张发布纹理控制在 4096 × 4096 以内，并避免让所有角色载入巨大重复画布。客户端负责绘制，不能为了美术给 2 核 2 GB 服务器添加图像生成或高频模拟负担。
- Phaser 与 DOM 回退路径使用同一资产语义、动作和足点。原始贴图可验证透明边缘，浏览器实景验证插值与缩放；测试中的 texture key 存在不等于图片美观。
- 资源可采集区域、道路、门户、池塘和阻挡区域的真实几何保持一致。装饰不能遮住可走路面却没有解释，也不能把不可采集树画得和资源树完全一样。

每轮把官方参考、v0.21 基线和新版相同视角放在一起肉眼检查，记录仍存在的混搭。以下任何一项存在就应继续修正：只换了地面；农场仍是旧像素村庄；人物和怪物仍是像素；装备或食物图标明显跳出新画风；全地面高频排线；角色像悬浮贴图；只能在裁切宣传图中看出风格而正常首屏看不到。

功能测试负责状态、交互、回归和资源可加载；视觉验收负责画风、尺寸、组合和舒适度。测试全绿不能替代肉眼审查，也不能作为“已达到饥荒参考方向”的唯一依据。

## 原始素材阶段审查记录

2026-11-01 已实际查看新的 environment、buildings、ground 原图，以及人物动作图和 farm-ground。建筑的歪屋顶、深墨轮廓、不同长木板和纸片透视方向成立；地面比 v0.21 安静。原图中松枝和矿石局部排线较密，随后已用默认镜头确认轮廓清楚，未叠加旧版全屏草纹。

前两个人物分别以绿色短外套 / 叶发饰、黄色长外套 / 宽檐帽区分，轮廓和色块统一。两张原图均为 1024 × 1536 RGBA，透明像素占 76.16% 和 75.76%，alpha 范围 0—254，四角和列间取样为 0；是实际透明图，不需要把预览的暗背景抠掉。3 列对应正面、背面和侧面，8 行提供基础动作姿态。最终 manifest 的 17 动作、3 个原始方向、west 镜像和 4 阶段同步已经通过检查；8 个人物联系表和世界中的实际形象均已查看。少数准备姿态使用单独生成的透明补图，逐帧 image / scale / sheet dimensions 覆盖已验证。

farm-ground 是 1536 × 1024 RGB，不透明背景符合用途。上中是围栏入口，上右是棚屋，中央保留田地和人物的空间。桌面和手机实景已确认按新宽高比显示，人物、四垄作物及状态铭牌位于中央空地，没有落到棚屋或外侧树根上。

原始环境与建筑图并非严格的 4 × 3 等高网格，首排树和屋脚跨过高度三分之一的位置；最终使用实际矩形与足点采样。早期长凳与石柱重叠的问题已用独立补图解决，正式图层不再引用重叠单元。

原图审查后的实景问题也已完成修正：营地厨房、补给台和资源堆缩小绘制，真实位置保持不变；资源的亮色标记改为交互时出现；道路由规则双线带改成低对比土路；池塘使用原阻挡区域内的不对称岸线和短水纹。最终截图已复核这些修改。

## 自动检查的使用与迁移
