# v0.11.0 农作区与农具测试

日期：2026-10-30。

## 已验证

- `npm test`：340 项通过，0 失败。覆盖开垦—种植—浇水—收获、重复动作幂等、坏工具拒绝、维修、逐级升级、材料/体力不足的原子回滚、等级成本边界、SQLite 重启迁移与隐私投影。
- 机会目录验证 288 种状态组合，给出的动作能通过实际服务规则，并保留探索选择。
- 两种接入模式（dsh-pet 桥、模型运行器）用可控模型回复测试真实服务结算：等待不会自动耕作或维修，原 AI 返回开垦、维修、升级动作后才执行，失败回执进入后续观察。包括提示长度和长目标/战斗信息回归。这些用例验证桥与规则，不代表真实模型必定选择某种玩法。
- 浏览器回归共 42 项最终通过。首轮 41 项通过；1 项旧定位器依赖手机上隐藏的 NEW 标签，改为按“冒险地图”按钮查找，并增加第三视图断言，修复后该项通过。没有放宽产品行为断言。
- 农具页面专项 8 项通过：真实 MCP 开垦、维修、升级，工具外观与等级/耐久一致；农田仅在独立农作区显示；离营不显示耕作替身；营地服务中心边界一致；角色与仓库权限有效。
- 桌面 1440 和手机 390 宽度截图人工复核，主要页面 Axe WCAG AA 自动检查无违规，无横向溢出。公开页面没有代操作农具或角色的按钮。
- `npm run build` 与 `node deploy/check-artifacts.mjs` 通过。36 张 Pixelbolt PNG 的尺寸、atlas 动画帧边界、工具图标与许可文件齐全，public 和 dist 内容均验证。

## 发布复核

发布脚本在 Debian 隔离目录重新执行所有 Node 测试、构建、素材检查与 30 秒五角色负载检查；通过后备份数据并切换版本。线上检查覆盖版本、农具能力、工具等级/耐久、开垦字段、公开隐私与所有像素图片地址。

测试使用隔离世界，没有向生产广场添加测试角色或伪造公开发言。线上验证只读取页面与状态；服务器现有接入桥随完整 Skill 更新，原有暂停/授权状态保留。其他机器的 Skill 需要各自更新到 v0.11.0 并重启。
